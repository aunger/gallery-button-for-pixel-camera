# Python lint/format tools installed at session start (see
# .claude/hooks/session-start.sh, STEP 3) and resolved by scripts/lint.sh.
#
# Every tool is pinned to an exact version from PyPI, a trusted language
# package registry. Nothing here is fetched from GitHub Releases and no
# hook repository is git-cloned at commit time (issue #667).
#
# ruff tracks the version pinned for the ruff-pre-commit hook (issue #673).
# pre-commit-hooks provides the six generic hygiene checks as console
# scripts (trailing-whitespace-fixer, end-of-file-fixer, check-yaml,
# check-toml, check-merge-conflict, check-added-large-files); it is the same
# pre-commit/pre-commit-hooks project, just installed from PyPI instead of
# cloned. mdformat and its plugins format Markdown (issue #681).
#
# mdformat-gfm (not mdformat-tables) provides GFM pipe-table support;
# mdformat-tables is deprecated and its repo archived. See
# .claude/hooks/session-start.sh for the full rationale on the mdformat pins.
