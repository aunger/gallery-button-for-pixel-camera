# Instructions for agents

The development-orchestration workflow (Orchestrator, Author, Reviewer, CI
Watcher) and its conduct rules now live in the `orchestrate` plugin under
`.claude/skills/orchestrate/`. Kick it off with the `/orchestrate` skill.

- If addressing a GitHub issue or PR without a specific assigned role, read `./.claude/skills/orchestrate/rules/orchestration.md`.
- If participating in a PR or review (as Author, Reviewer, or Orchestrator), read `./.claude/skills/orchestrate/rules/review_cycle.md`.
- If editing code or creating a PR, read `./.claude/skills/orchestrate/rules/authoring.md`.
